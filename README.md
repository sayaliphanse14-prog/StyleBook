# StyleBook – Salon Appointment Booking System

StyleBook is a **MERN stack web application** designed for salons to manage services and customer appointments digitally.

## Features

* User registration and login
* JWT-based authentication
* View salon services and prices
* Book salon appointments
* View and manage appointments
* Cancel appointments
* REST API integration using Axios
* MongoDB database for storing users, services and appointments
* Responsive and user-friendly interface

## Tech Stack

**Frontend:** React.js, Axios, React Router
**Backend:** Node.js, Express.js
**Database:** MongoDB
**Authentication:** JWT, bcrypt
**Tools:** VS Code, Postman, Git & GitHub

## Project Structure

```text
StyleBook/
├── frontend/       # React frontend
├── backend/        # Express REST API
└── practical7-nodejs-core/
```

## How It Works

**Customer → React Frontend → Axios → Express REST API → MongoDB**

Users can register/login, browse available salon services, book appointments and manage their bookings through the website.

## Purpose

The project was developed as a practical **digital booking solution for a local salon business**, with the possibility of customizing the services, prices and business details according to the salon's requirements.
